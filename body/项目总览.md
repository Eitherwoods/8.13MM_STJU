## 二、建模思路与创新点（§5-7 主体素材）

### 问题1：单向出海运输

- **模型**：集合划分 MIP（路径-需求覆盖）
- **算法**：两阶段ε-容差组合法
  - 阶段一：最小化总飞机使用时间 → 得 T*
  - 阶段二：在 T ≤ (1+ε)T* 容差带内（ε=3%），AHP加权优化二级目标（在途时间τ、浪费座公里W、燃油F）
  - 路径生成：Clarke-Wright节省算法，按1/2/3/4-5设施分级
  - 分数目标线性化：Dinkelbach迭代
- **AHP权重**：w_τ=0.625, w_util=0.2385, w_fuel=0.1365（CR<0.1通过一致性检验）
- **创新点**：加油中转点嵌入、ε-容差带内系统优化、浪费座公里作利用率线性代理、帕累托支配论证
- **关键洞察**：单向出海存在50%座位利用率上界（命题3：去程载客/返程空载，客座公里≤½可用座公里）
- **可写理论**：命题3的证明（利用率上界）、定理1（Dinkelbach收敛性）

### 问题2：出海、海返与穿梭联合运输

- **模型**：三类需求（出海/海返/穿梭）统一集合划分 MIP + 航段级容量约束
- **算法**：沿用Q1两阶段框架，新增座位即时复用机制（"先下后上"，座位在航段间即时释放）
- **创新点**：航段级容量约束、座位复用突破50%上界（实测86.58%）、穿梭OD对专用路径生成
- **核心发现**：座位复用倍数约2.13，人均油耗较Q1降54.9%
- **可写理论**：定理2（座位复用下利用率上界提升至1）、推论（复用倍数与航段数关系）

### 问题3：带时间要求的多日排班

- **数据洞察**：4000条需求（出海1600+海返1600+穿梭800），其中临时任务160人；84.1%的需求时间窗跨天（均值41.6h）；24架飞机（3机场×3机型，8+8+8）
- **模型**：按天解耦定理（定理1）+ 时间扩展网络（C6）+ 加权单目标MIP + 背包化
- **两阶段结构**：
  - **阶段一**（3840人）：按天解耦为7个独立单日 → 需求-日期分配 → CPM收缩 + 受限路径池 + COPT MIP → 汇总 T*
  - **阶段二**（160临时任务）：在 T ≤ T* 约束下，背包化最大化装入（优先利用已有架次空余座位）
- **完整权重**：(w_time, w_transit, w_util, w_fuel) = (1.0, 0.01, 0.15, 0.005)，经Pareto前沿分析验证为唯一最优
- **9项创新点**：

### 权重敏感性分析（各8组）

- Q1："偏时间+燃油"方案架次最少(92)、时间最短之一(15575)
- Q2："偏燃油消耗"方案时间最短(18400)、利用率最高(91.41%)
- 求解时间：Q1 9.7-90.8s，Q2 大部分达300s上限

### ε-容差敏感性分析（Q1，7组ε值）

- ε从0%→10%，总时间增7.3%，在途时间降10.4%，利用率降2.06pp，燃油增5.5%
- ε=0%~1%：容差过紧，求解器无法找到更优二级目标解，回退到阶段一解（T=T*）
- ε=2%~3%：首次出现有效改善，在途时间降5.7%，时间退化1.86%
- ε=5%：最优折中点（综合得分=-0.0246），在途时间降6.1%，时间仅退化1.51%
- ε=8%~10%：在途时间进一步改善但边际递减，燃油代价显著增大
- 论文可画G9论证：ε=5%为时间-二级目标权衡的最佳折中点
