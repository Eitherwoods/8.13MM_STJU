# 问题3：带时间要求的多日排班 — 建模与求解方案

## 1 问题分析

### 1.1 问题本质

问题3在问题2（4000条出海/海返/穿梭联合需求）的基础上叠加了三层新约束：

1. **时间窗约束**：每条需求有 `earliest_pickup_time`（最早登机时刻）和 `latest_arrival_time`（最晚到达时刻），飞机离开起点不得早于前者，到达终点不得晚于后者
2. **机队数量约束**：仅24架飞机（A01: 3T1+3T2+2T3=8架，A02: 2T1+4T2+2T3=8架，A03: 2T1+3T2+3T3=8架），每架飞机规划期内可用
3. **运营时段约束**：飞机06:00–18:00起飞，不晚于20:00返回机场，不得在海上设施过夜；相邻架次间至少30分钟周转

任务分为四类（应急处置/增储上产/常规倒班/临时任务），临时任务可被取消。问题要求两阶段求解：**阶段一**在不考虑临时任务的情况下编排（3840人），得到总飞机使用时间 $T^*$；**阶段二**在总时间不超过 $T^*$ 的前提下，尽可能多地满足临时任务（160人）。

### 1.2 数据洞察

对 `peopleQ3.csv` 的实际统计（关键事实，用于建模决策）：

| 数据特征 | 数值 | 对建模的影响 |
|:---|:---|:---|
| 总需求 | 4000人（出海1600 + 海返1600 + 穿梭800） | 与Q2相同的OD结构，可复用Q2路径池 |
| 任务类型 | 常规倒班3440、增储上产360、应急处置40、临时任务160 | 阶段一3840人，阶段二加160人 |
| 时间窗宽度 | min=28min，max=8691min（约6天），mean=2496min（约41.6h） | **时间窗普遍跨天**，需求的可调度日期非唯一 |
| 跨天比例 | 84.1%的需求时间窗跨天（覆盖2~7天） | 需求-日期分配有充分自由度 |
| 日期分布 | 2026-08-03至08-09共7天，每日非临时需求294~815人 | 按天解耦的基础；08-09全部为同日时间窗 |
| 临时任务 | 160人，时间窗极宽（min=32h, mean=81h），全部跨天 | 阶段二背包插入的有利条件 |
| 23:59到达 | 785条需求（19.6%）的latest_arrival=23:59 | 实际约束为"当天内到达"，因飞机20:00前必须返场 |

**关键洞察1（按天解耦）**：题目给出三条事实——飞机不得海上过夜、每个架次都返回所属机场、运营时段为当日06:00–20:00。由此可推得：**任意架次的起飞与返回发生在同一自然日内**，即不存在跨天状态耦合。多日排班问题可严格分解为7个独立的单日问题，每日机队状态"重置"。

**关键洞察2（时间窗跨天）**：虽然架次不跨天，但需求的时间窗普遍跨天（84.1%，均值41.6小时），一条需求可安排在时间窗覆盖的任意一天。这给"需求-日期分配"提供了优化自由度：可将需求灵活分配到负载较低的日子，均衡每日运力压力。但08-09的294条需求全部为同日时间窗，无法转移。

**关键洞察3（时间窗只影响可行性/时刻，不改变容量结构）**：Q2已建立"先下后上、座位即时释放"的航段级容量约束。时间窗约束只限制"某条路径上的停靠时刻是否可行"，不改变航段容量模型本身——Q2的容量约束结构可原样迁移，只需在路径上叠加时刻变量。

### 1.3 核心难点

1. **时间窗可行性**：路径可行不仅要满足燃油和容量，还要为每个人员找到满足其 [最早登机, 最晚到达] 的时刻分配
2. **机队资源约束**：24架飞机（按机型分配）如何分配到7天、每天如何串联多个架次（30分钟周转、运营时段、不得过夜）是全新的资源调度维度
3. **两阶段耦合**：阶段二必须在阶段一总时间 $T^*$ 不增加的约束下插入临时任务，需要精确刻画"剩余时间缝隙+空余座位"资源
4. **路径池爆炸**：加入时间维度后，同样的OD组合在不同起飞时刻对应不同路径，路径池规模远大于Q1/Q2

## 3 理论基础

### 3.1 定理1（按天解耦）

**定理1**　给定约束"飞机不得在海上设施过夜、每个架次必须返回所属机场、飞机06:00–18:00起飞且不晚于20:00返回"，任意架次的起飞时刻与返回时刻必在同一自然日内。

**证明**　设架次在 $d$ 日 $t$ 时刻起飞（$t \geq 06:00$）。若返回时刻落在 $d+1$ 日，则飞机在海上设施停留跨过午夜，违反"不得在海上设施过夜"；若飞机在返回前停留于机场，则架次已在 $d$ 日结束。故架次不可能跨天。∎

**推论1.1（日间独立）**　由于架次不跨天、飞机每日从所属机场重置出发，各日之间不存在状态转移耦合。多日排班问题可精确分解为 $D=7$ 个独立的单日问题：

$$\min \sum_{d=1}^{7} Z_d, \quad Z_d = \text{第 } d \text{ 日最优目标值}$$

**推论1.2（需求-日期可行集）**　对需求 $p$，其可行日期集合为 $D_p = \{ d : \text{时间窗}[e_p, l_p] \text{ 与第 } d \text{ 日运营时段 } [06{:}00, 20{:}00] \text{ 有交集} \}$。由于84.1%的需求时间窗跨天，$|D_p| \geq 2$ 常成立，为需求-日期分配提供自由度。

### 3.2 命题2（时间窗CPM收缩）

**命题2**　对候选路径 $r = [A, S_1, \ldots, S_K, A]$，设 $P_k^{\text{board}}$ 为在停靠点 $k$ 登机的需求集合，$P_k^{\text{alight}}$ 为在停靠点 $k$ 到达的需求集合。定义前向最早到达时刻与后向最晚离开时刻：

$$\text{EAT}_k = \max\!\left(\text{EAT}_{k-1} + \frac{d_{k-1,k}}{v} \times 60 + s_{k-1},\; \max_{p \in P_k^{\text{board}}} e_p\right)$$

$$\text{LDT}_k = \min\!\left(\text{LDT}_{k+1} - \frac{d_{k,k+1}}{v} \times 60,\; \min_{p \in P_k^{\text{alight}}} l_p\right)$$

其中 $s_k$ 为停靠时间（加油20min/普通10min），$d_{k,k+1}$ 为航段距离，$v$ 为机型速度。边界条件：$\text{EAT}_0 = 06{:}00$，$\text{LDT}_{K+1} = 20{:}00$。

**若 $\exists\, k$ 使得 $\text{EAT}_k > \text{LDT}_k$，则路径 $r$ 不可行，直接剔除。** 否则路径可行起飞窗口为 $[E_r, L_r] = [\text{EAT}_0, \text{LDT}_0]$。此收缩为纯数学预处理，以 $O(K)$ 代价在路径生成阶段剔除时间窗不可行路径。

**注**　对于 $l_p = 23{:}59$ 的需求（占19.6%），因飞机20:00前必须返场，有效最晚到达时刻应收缩为 $\min(l_p, 20{:}00)$。对 $e_p < 06{:}00$ 的需求（占7.7%），有效最早登机时刻应取 $\max(e_p, 06{:}00)$。

### 3.3 命题3（座位利用率上界，承接Q2）

**命题3**　单向出海运输的座位利用率上界为50%。去程载客、返程空载，客座公里 $\leq \frac{1}{2} \times$ 可用座公里。联合运输通过海返与穿梭消除返程空载，可突破该上界（Q2实测84.48%）。

### 4.2 单日问题模型（阶段一核心）

#### 符号说明

沿用Q2符号体系，并扩展：

| 符号 | 含义 |
|:---|:---|
| $\mathcal{R}_d$ | 第 $d$ 日候选路径池（受限生成） |
| $\mathcal{M}_{a,t}$ | 机场 $a$ 的 $t$ 型机队数量（如 $\mathcal{M}_{A01,T1}=3$） |
| $t^{dep}_{r}, t^{ret}_{r}$ | 路径 $r$ 的起飞/返回时刻（固定值，由CPM确定） |
| $[E_r, L_r]$ | 路径 $r$ 可行起飞时刻窗口（由CPM收缩计算） |
| $y^O_{r,f}, y^I_{r,f}, y^S_{r,(f_1,f_2)}$ | 同Q2，出海/海返/穿梭人数分配 |

#### 决策变量

$$x_r = \begin{cases} 1 & \text{路径 } r \in \mathcal{R}_d \text{ 被选中} \\ 0 & \text{否则} \end{cases}$$

$$y^{O}_{r,f}, y^{I}_{r,f}, y^{S}_{r,(f_1,f_2)} \in \mathbb{Z}_{\geq 0} \quad \text{（同Q2）}$$

#### 约束条件

**约束1：需求覆盖（同Q2，按日）** — 第 $d$ 日需求全部覆盖

$$\sum_{r} y^{O}_{r,f} = n^{O}_{d,f}, \quad \sum_{r} y^{I}_{r,f} = n^{I}_{d,f}, \quad \sum_{r} y^{S}_{r,(f_1,f_2)} = n^{S}_{d,(f_1,f_2)}$$

**约束2：航段级容量（同Q2，原样迁移）**

$$\sum_{f \in \mathcal{F}^{O}_k} y^{O}_{r,f} + \sum_{f \in \mathcal{F}^{I}_k} y^{I}_{r,f} + \sum_{(f_1,f_2) \in \mathcal{S}_k} y^{S}_{r,(f_1,f_2)} \leq c_r \cdot x_r$$

**约束3：时间窗（命题2，路径生成时预收缩）** — 每条路径起飞时刻 $t^{dep}_r$ 取固定值 $\in [E_r, L_r]$，路径生成时已确保所有可能需求的时间窗均可满足。需求-路径兼容性在路径生成阶段预计算，MIP中仅对兼容的 $(r, p)$ 对创建 $y$ 变量。

**约束4：机队约束（创新点C6，按机型分解）** — 对每个机场 $a$、机型 $t$、时间槽 $\tau$：

$$\sum_{\substack{r \in \mathcal{R}^{a,t}_d \\ \tau \in [t^{dep}_r,\; t^{ret}_r + 30]}} x_r \leq |\mathcal{M}_{a,t}|$$

其中 $\mathcal{R}^{a,t}_d$ 为第 $d$ 日从机场 $a$ 出发、使用机型 $t$ 的路径集合，$t^{ret}_r + 30$ 含30分钟周转。时间槽以10分钟粒度离散化 $[06{:}00, 20{:}00]$ 共84个槽。同时满足：
- 起飞时刻 $\in$ [06:00, 18:00]，返回时刻 $\leq$ 20:00

**约束5：燃油可行性（同Q1/Q2）** — 加油中转点嵌入机制复用。

#### 目标函数（同Q2，字典序四目标）

$$\min \underbrace{\sum_r t_r x_r}_{\text{①总时间}} \to \min \underbrace{\sum \tau y}_{\text{②在途}} \to \max \underbrace{\frac{\text{pass\_km}}{\text{seat\_km}}}_{\text{③利用率(Dinkelbach)}} \to \min \underbrace{\sum \text{fuel}_r x_r}_{\text{④燃油}}$$

### 4.3 受限路径池 + 时间窗过滤（创新点C3）

Q3时间维度使路径池爆炸，采用与Q1/Q2一致的**受限路径池**策略并叠加时间窗过滤：

1. 复用Q1/Q2的Clarke-Wright节省算法生成多设施路径（空间维度）
2. 对每条路径运行命题2时间窗收缩：时间窗不可行→剔除；可行→记录起飞窗口 $[E_r, L_r]$（时间维度）
3. 固定起飞时刻为 $E_r$（最早可行时刻），计算各停靠点的到达/离开时刻
4. 对每个需求 $p$，检查其时间窗是否与路径固定时刻兼容；仅对兼容的 $(r, p)$ 对在MIP中创建变量
5. 按日归集：路径只需在需求时间窗覆盖的日期可行

进阶方案（论文中作为对比提及）：若时间充裕可采用**列生成/分支定价**——主问题为集合划分，定价子问题为带资源约束的最短路径（ESPPRC）。

### 4.4 阶段二：临时任务背包化（创新点C4）

阶段一固定排班确定后，剩余资源为"时间缝隙 + 空余座位"。将问题重构为**最大覆盖/背包问题**：

- **物品**：每个临时任务 $p$，占用某架次 $r$ 的若干座位与时间窗资源
- **背包容量**：阶段一总时间 $T^*$ 不增加的约束 + 各架次空余座位
- **目标**：最大化满足的临时任务数

$$\max \sum_{p \in \mathcal{P}_{temp}} z_p \quad \text{s.t.} \quad \sum_{p} \text{load}_{r,p} \cdot z_p \leq \text{spare}_r, \quad \sum_r t_r \leq T^*$$

**实现策略**：
1. **优先插入已有架次**：若临时任务的OD恰在已有架次路径上且有空余座位、时刻兼容，则零新增时间插入
2. **次选新增架次**：插入失败时尝试新架次（需在 $T^*$ 预算内），新增架次带来额外时间消耗
3. 临时任务时间窗极宽（均值81小时），插入兼容性好

**上界推导**：

$$\text{UB}_{\text{temp}} = \min\left( |\mathcal{P}_{temp}|, \left\lfloor \frac{\sum_r \text{spare}_r}{\min_p \text{load}_p} \right\rfloor \right)$$

此上界较宽松（不考虑OD匹配与时刻兼容性），实际满足数可能低于上界，需结合实验结果分析间隙。

### 4.5 下界证明 + 最优性间隙认证（创新点C5）

| 下界/上界 | 公式 | 用途 |
|:---|:---|:---|
| 架次数下界 | $\lceil \frac{\text{日需求总量}}{\max c_r} \rceil$ | 证明每日架次接近最优 |
| 总时间下界 | $\sum_{\text{架次}} (\text{最低飞行时间} + \text{停靠时间})$ | 证明总时间间隔小 |
| 临时任务满足上界 | 由剩余座位×航程导出 | 证明阶段二装载充分 |

用"我们的解与下界的间隔只有 X%"论证解质量，而非依赖求解器声明。

## 5 算法设计流程

```
阶段一:
  [1] 数据预处理：解析时间窗，构建需求-日期可行集 D_p（定理1推论1.2）
      - 有效时间窗收缩：e_p' = max(e_p, 06:00), l_p' = min(l_p, 20:00)
  [2] 需求-日期分配：跨天需求选择负载最小的可行日期，均衡每日运力（贪心）
  [3] 逐日求解（7次，可并行）：
      3a. 路径生成：复用Q1/Q2节省算法生成候选路径
      3b. 时间窗CPM收缩（命题2）：剔除不可行路径，计算起飞窗口
      3c. 固定起飞时刻 → 计算各停靠时刻 → 需求-路径兼容性检查
      3d. 机队-时间扩展网络（C6）：10分钟粒度离散化，按机型分解约束
      3e. COPT MIP求解：字典序四目标 + Dinkelbach迭代（复用Q2求解器结构）
  [4] 汇总7日结果 → T*
阶段二:
  [5] 临时任务背包化（C4）：优先插入已有架次空余座位 → 不足时新增架次（T*预算内）
  [6] 上界计算与间隙认证（C5）
输出:
  [7] q3-routes.csv（含时刻）+ q3-assignments.csv（临时未安排者留空）
```
