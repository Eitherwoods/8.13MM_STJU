# 问题1：单向出海运输 — 建模与求解说明

## 1 问题分析

### 1.1 问题本质

问题1要求为1600条单向出海需求编排直升机运载计划。每条需求的起点为陆地机场（具体机场或LAND表示任意机场），终点为海上设施。需要决策的内容包括：

- 每个架次的起降机场、机型、停靠设施序列
- 每个架次中运往各设施的具体人数
- 每名人员分配到的具体架次

这是一个典型的**带容量约束的路径编排问题**，可归类为**集合划分问题（Set Partitioning Problem, SPP）**的变体，属于NP-hard问题。

### 1.2 核心难点

1. **组合爆炸**：3个机场 × 52个设施 × 3种机型，可能的架次路径数量呈指数增长，尤其是多设施联合路径的排列组合极大
2. **燃油可行性**：不同机型的油箱容量和安全余油量不同，长距离多设施路径可能需要中途加油，加油决策本身是一个离散优化子问题
3. **多目标优化**：题目要求在最小化总飞机使用时间的基础上，尽可能优化座位利用率、油耗等因素，需要设计合理的多目标处理策略
4. **起点感知**：部分人员指定了出发机场（如A01），部分人员可接受任意机场（LAND），需要区别处理

### 1.3 关键洞察

- **路径预生成 + 集合划分**是解决大规模VRP问题的经典两阶段框架：先生成一批高质量候选路径，再用MIP从中选优，兼顾求解效率和解质量
- **加油中转点嵌入**：当路径燃油不可行时，不是直接放弃，而是尝试在路径中插入可加油设施作为中转站，扩展可行路径池
- **字典序多目标优化**：利用COPT求解器的原生多目标功能（`setObjectiveN`），按优先级分层优化，避免手动约束传递带来的热启动问题

## 2 模型建立

### 2.1 符号说明

| 符号 | 含义 |
|:---|:---|
| $\mathcal{A}$ | 陆地机场集合 $\{A01, A02, A03\}$ |
| $\mathcal{F}$ | 海上设施集合 $\{F001, \ldots, F052\}$ |
| $\mathcal{R}$ | 候选路径集合（预生成） |
| $\mathcal{T}$ | 机型集合 $\{T1, T2, T3\}$ |
| $d_{ij}$ | 地点 $i$ 到 $j$ 的飞行距离 (km) |
| $n_f$ | 设施 $f$ 的需求人数 |
| $n_{f,a}$ | 设施 $f$ 中起点为机场 $a$ 的需求人数 |
| $c_r$ | 路径 $r$ 的座位数（由机型决定） |
| $t_r$ | 路径 $r$ 的总时间（分钟） |
| $\text{fuel}_r$ | 路径 $r$ 的总油耗 (kg) |
| $\tau_{r,f}$ | 路径 $r$ 中人员到设施 $f$ 的在途时间（分钟） |
| $\mathcal{F}_r$ | 路径 $r$ 经停的目标设施集合 |
| $a_r$ | 路径 $r$ 的起降机场 |

### 2.2 决策变量

$$x_r = \begin{cases} 1 & \text{路径 } r \text{ 被选中} \\ 0 & \text{否则} \end{cases} \quad r \in \mathcal{R}$$

$$y_{r,f} \in \mathbb{Z}_{\geq 0} \quad \text{路径 } r \text{ 运往设施 } f \text{ 的人数}, \quad r \in \mathcal{R},\ f \in \mathcal{F}_r$$

### 2.3 约束条件

**约束1：需求满足** — 每个设施的需求必须被完全覆盖

$$\sum_{r \in \mathcal{R}: f \in \mathcal{F}_r} y_{r,f} = n_f \quad \forall f \in \mathcal{F}$$

**约束2：起点感知** — 指定机场出发的人员必须由该机场的路径服务

$$\sum_{r \in \mathcal{R}: f \in \mathcal{F}_r,\ a_r = a} y_{r,f} \geq n_{f,a} \quad \forall f \in \mathcal{F},\ a \in \mathcal{A},\ n_{f,a} > 0$$

**约束3：容量约束** — 每条路径的总运输人数不超过座位数

$$\sum_{f \in \mathcal{F}_r} y_{r,f} \leq c_r \cdot x_r \quad \forall r \in \mathcal{R}$$

### 2.4 目标函数（字典序多目标）

利用COPT的`setObjectiveN`实现三层字典序优化：

**第一优先级（最高）：最小化总飞机使用时间**

$$\min \sum_{r \in \mathcal{R}} t_r \cdot x_r$$

**第二优先级：最小化总燃油消耗量**

$$\min \sum_{r \in \mathcal{R}} \text{fuel}_r \cdot x_r$$

**第三优先级（最低）：最小化人员总在途时间**

$$\min \sum_{r \in \mathcal{R}} \sum_{f \in \mathcal{F}_r} \tau_{r,f} \cdot y_{r,f}$$

## 3 算法设计

### 3.1 总体架构：两阶段法

```
┌─────────────────────────────────────────────┐
│            第一阶段：路径生成                  │
│  ┌─────────┐  ┌─────────┐  ┌─────────────┐  │
│  │单设施路径│→ │双设施路径│→ │三~五设施路径 │  │
│  └─────────┘  └─────────┘  └─────────────┘  │
│       │            │              │          │
│       ▼            ▼              ▼          │
│  ┌──────────────────────────────────────┐   │
│  │     燃油可行性检查 + 加油中转点嵌入    │   │
│  └──────────────────────────────────────┘   │
│                  │                           │
│                  ▼                           │
│         候选路径池 $\mathcal{R}$              │
└─────────────────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────┐
│         第二阶段：COPT MIP 求解               │
│  ┌──────────────────────────────────────┐   │
│  │  集合划分MIP + 字典序多目标优化       │   │
│  │  setObjectiveN(priority=10/5/1)      │   │
│  └──────────────────────────────────────┘   │
│                  │                           │
│                  ▼                           │
│          最优路径选择 + 人员分配              │
└─────────────────────────────────────────────┘
```

### 3.2 第一阶段：路径生成

路径生成采用**分层扩展策略**，从单设施路径逐层扩展到多设施路径：

**第1层：单设施路径** — 枚举所有 (机场, 设施, 机型) 组合，共 $3 \times 52 \times 3 = 468$ 种基本组合。

**第2层：双设施路径** — 基于**Clarke-Wright节省算法**，计算设施对的节省值：

$$s(f_1, f_2) = d_{f_1, a} + d_{a, f_2} - d_{f_1, f_2}$$

节省值越大，说明将两个设施合并到同一架次越有利。按节省值降序排列，每机场取前200对，用TSP暴力求解最优设施顺序。

**第3层：三设施路径** — 从最优双设施路径扩展，仅考虑与现有设施距离100km以内的候选设施，限制总数300条。

**第4层：四~五设施路径** — 从最优三设施路径扩展，距离阈值递减（80km→60km），限制总数300条。

### 3.3 燃油可行性检查与加油中转点嵌入

**创新点1：暴力枚举最优加油策略**

给定路径 $[a, f_1, f_2, \ldots, f_K, a]$，找出路径中所有可加油设施位置。通过位掩码枚举所有加油组合（最多 $2^5 = 32$ 种），选择加油次数最少且可行的方案。

**创新点2：加油中转点嵌入**

当原始路径燃油不可行时，尝试在路径中插入可加油设施作为中转站。具体做法：遍历8个可加油设施和所有可插入位置，选择使总航程最短的可行增广路径。

### 3.4 第二阶段：COPT多目标MIP求解

使用COPT（Cardinal Optimizer）的`setObjectiveN`接口实现字典序多目标优化：

| 目标 | 优先级 | 相对容差 | 说明 |
|:---|:---:|:---:|:---|
| 总飞机使用时间 | 10 | 1% | 主目标，求解时间180s |
| 总燃油消耗量 | 5 | 5% | 次要目标 |
| 人员总在途时间 | 1 | 5% | 辅助目标 |

COPT按优先级从高到低依次优化各目标，高优先级目标的最优值作为低优先级目标的约束上限（允许指定相对容差内的退化），且自动使用前一阶段的解作为热启动。

### 3.5 人员分配

MIP求解得到选中路径集和各路径运往各设施的人数后，需要将具体人员分配到路径。分配策略：

1. 按设施分组所有待运人员，特定机场人员优先于LAND人员
2. 对每条选中路径的每个目标设施，先匹配起点为该路径机场的人员
3. 剩余名额用LAND人员补充

## 5 创新点总结

1. **加油中转点嵌入**：当路径燃油不可行时，自动在路径中插入可加油设施作为中转站，显著扩展可行路径池覆盖率
2. **节省算法分层路径生成**：基于Clarke-Wright节省算法，按节省值排序逐层扩展，在控制路径数量的同时保证路径质量
3. **COPT原生字典序多目标优化**：利用`setObjectiveN`实现三层目标分层优化，避免手动约束传递的热启动问题
4. **起点感知需求约束**：对指定机场出发的人员添加专属约束，确保LAND人员灵活分配而指定机场人员严格匹配
